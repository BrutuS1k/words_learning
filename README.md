# Слова

Карточки для запоминания слов. Работает как PWA: открывается в браузере телефона и ставится на домашний экран.

## Как запустить на телефоне
1. Выложите все файлы из папки на хостинг с HTTPS: GitHub Pages, Netlify (перетащить папку на app.netlify.com/drop) или Cloudflare Pages.
2. Откройте адрес на телефоне.
   - iPhone: Safari, «Поделиться», «На экран Домой».
   - Android: Chrome, меню, «Установить приложение».

## Экраны
Выбор языка, выбор режима, список слов (по алфавиту, с удалением), добавление слова, карточки. Тёмный Soft UI с мятным акцентом.

## Данные
Языки и слова хранятся в браузере телефона (localStorage). Подсказки, транскрипция и перевод запрашиваются онлайн, а записываются локально. Карточки работают без интернета.

## Источники словарей
- Английский: подсказки Datamuse (запасной вариант: Wiktionary), транскрипция dictionaryapi.dev (запасной вариант: английский Wiktionary).
- Сербский (только латиница): подсказки sh.wiktionary, sr.wiktionary и лексемы Wikidata, кириллица переводится в латиницу автоматически; транскрипция английский Wiktionary. Если транскрипции нет, русское произношение строится по написанию слова.
- Остальные языки: Wiktionary этого языка и английский Wiktionary.
- Перевод на русский: один источник, Google Translate (открытый адрес без ключа, браузер обращается к нему напрямую). Если он недоступен, запасной вариант: Wiktionary и MyMemory. Показывается один вариант, его можно править вручную.

Язык выбирается из готового списка (около 40 языков). Без связи со словарём поле транскрипции блокируется.
