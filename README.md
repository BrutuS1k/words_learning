# Слова

Карточки для запоминания слов. Работает как PWA: открывается в браузере телефона и ставится на домашний экран.

## Как запустить на телефоне
1. Выложите все файлы из папки на хостинг с HTTPS: GitHub Pages, Netlify (перетащить папку на app.netlify.com/drop) или Cloudflare Pages.
2. Откройте адрес на телефоне.
   - iPhone: Safari, «Поделиться», «На экран Домой».
   - Android: Chrome, меню, «Установить приложение».

## Данные
Языки и слова хранятся в браузере телефона (localStorage). Подсказки и транскрипция берутся из Wiktionary, перевод из MyMemory. Они запрашиваются онлайн, а записываются локально. Карточки работают без интернета.
